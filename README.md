# Diabetic Retinopathy Detection Using Deep Learning

## Overview

Diabetic Retinopathy (DR) is a diabetes-related eye disease that can lead to vision loss if not detected early. This project uses Deep Learning and Computer Vision techniques to automatically classify retinal fundus images into different stages of diabetic retinopathy.

The system is built using **TensorFlow**, **EfficientNetB0**, and **Flask**, providing a complete pipeline from model training to web-based prediction.

---

## Features

- Detection of diabetic retinopathy from retinal fundus images
- Classification into 5 severity levels:
  - No DR
  - Mild
  - Moderate
  - Severe
  - Proliferative DR
- Deep Learning model based on EfficientNetB0
- Flask REST API for predictions
- Simple web frontend for image upload
- Image preprocessing and normalization
- Grad-CAM support for model interpretability
- Model training and evaluation scripts

## Model Details

### Base Model
EfficientNetB0 (Pretrained on ImageNet)

### Input Size

```python
224 × 224 × 3
```

### Output Classes

| Class | Description |
|---------|-------------|
| 0 | No DR |
| 1 | Mild |
| 2 | Moderate |
| 3 | Severe |
| 4 | Proliferative DR |

### Training Strategy

- Transfer Learning
- Data Augmentation
- Fine-Tuning
- Softmax Classification Layer
- Categorical Cross-Entropy Loss
- Adam Optimizer

## Model Workflow

1. User uploads retinal image.
2. Image is resized to 224×224.
3. Pixel values are normalized.
4. EfficientNetB0 extracts image features.
5. Classification layer predicts DR severity.
6. Prediction result is returned through Flask API.
